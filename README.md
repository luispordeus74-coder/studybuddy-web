# Study Buddy – Site de Divulgação

[![Website](https://img.shields.io/badge/Website-Online-brightgreen)](https://studybuddy.mobile.ufersa.dev.br)

Este é o repositório do **site oficial de divulgação** do aplicativo Study Buddy.  
O site será publicado via **AWS Amplify**, acessível em:

👉 [https://studybuddy.mobile.ufersa.dev.br](https://studybuddy.mobile.ufersa.dev.br)

---

## 📖 Sobre o Projeto

O **Study Buddy** é um aplicativo mobile voltado para estudantes universitários que desejam organizar seus estudos de forma inteligente e personalizada.  
O site tem como objetivo apresentar o app, suas funcionalidades e instruções de download.

---

## 🚀 Tecnologias Utilizadas

- **HTML5 + CSS3 + JavaScript**  
- [TailwindCSS](https://tailwindcss.com/) para estilização  
- [AWS Amplify](https://aws.amazon.com/amplify/) para publicação  
- Integração com DNS `ufersa.dev.br`

---

## 📦 Como Executar Localmente

Se você quiser rodar o site localmente para desenvolvimento:

1. Clone o repositório:

```bash
git clone https://github.com/luispordeus74-coder/studybuddy-web.git
```

2. Navegue até a pasta do projeto:

```bash
cd studybuddy-web
```

3. Abra o arquivo `index.html` no navegador ou configure um servidor local (ex.: VS Code Live Server).
